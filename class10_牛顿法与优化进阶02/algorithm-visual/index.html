XGBoost Second-order Gradient Boosting

使用平方误差目标的二阶统计量，展示树模型逐轮拟合及训练损失变化。

叶子权重与分裂增益

教学版以一维回归树进行贪心分裂，使用 G/H 统计量和 L2 正则。

训练流程

  1. 初始化为目标均值
  2. 计算梯度 G 与 Hessian H
  3. 枚举切分点并计算增益
  4. 递归生成受深度限制的树
  5. 按学习率累加树输出

实验说明

  • 数据为确定性合成回归样本。
  • 树数、深度、学习率与 λ 均可输入。
  • 此为教学实现，不覆盖官方库的全部工程优化。

06

LightGBM Leaf-wise Growth

根据当前叶子候选分裂增益，优先扩展收益最大的叶节点。

分裂增益

实现使用平方误差梯度与 Hessian，计算候选阈值的增益。

Leaf-wise 流程

  1. 根节点作为初始叶子
  2. 计算各叶子的最佳二分候选
  3. 选择增益最大的叶子进行分裂
  4. 更新候选叶子，直到约束满足

参数解释

  • 叶子数控制树复杂度。
  • 最大深度限制路径长度；-1 表示不额外限制。
  • 最小增益用于过滤收益不足的切分。
